Overview

JavaScript implementation of Bitcoin BIP39: Mnemonic code for generating deterministic keys.

This library is a drop‑in replacement for the original bip39 package, with additional build optimizations and Monti‑specific integrations. It is used across the Monti stack for secure key generation and recovery.

Reminder for Developers

Please remember to allow recovery from mnemonic phrases that have invalid checksums (or that you don't have the wordlist).

When a checksum is invalid, warn the user that the phrase is not something generated by your app, and ask if they would like to use it anyway. This way, your app only needs to hold the wordlists for your supported languages, but you can recover phrases made by other apps in other languages.

However, there should be other checks in place, such as checking to make sure the user is inputting 12 words or more separated by a space. e.g. phrase.trim().split(/\s+/g).length >= 12.

Monti best practice: Always call bip39.validateMnemonic(phrase) before attempting recovery; it handles checksum validation internally and returns a boolean.

Removing Wordlists from Webpack / Browserify

Browserify/Webpack bundles can get very large if you include all the wordlists, so you can now exclude wordlists to make your bundle lighter.

Browserify Example

If you want to exclude all wordlists except chinese_simplified, build using the command below:

```bash
browserify -r bip39 -s bip39 \
  --exclude=./wordlists/english.json \
  --exclude=./wordlists/japanese.json \
  --exclude=./wordlists/spanish.json \
  --exclude=./wordlists/italian.json \
  --exclude=./wordlists/french.json \
  --exclude=./wordlists/korean.json \
  --exclude=./wordlists/czech.json \
  --exclude=./wordlists/portuguese.json \
  --exclude=./wordlists/chinese_traditional.json \
  > bip39.browser.js
```

This creates a bundle that only contains the chinese_simplified wordlist, which becomes the default for all calls without explicit wordlists.

Webpack 5 Example

Use the IgnorePlugin to exclude non‑English wordlists:

```javascript
// webpack.config.js
const webpack = require('webpack');

module.exports = {
  // ... other config
  plugins: [
    new webpack.IgnorePlugin({
      checkResource(resource) {
        // Keep only the English wordlist; change 'english' to any other language
        return /.*\/wordlists\/(?!english).*\.json/.test(resource);
      },
    }),
  ],
};
```

Console Output (when keeping only Chinese Simplified)

```javascript
> bip39.entropyToMnemonic('00000000000000000000000000000000')
"的 的 的 的 的 的 的 的 的 的 的 在"
> bip39.wordlists.chinese_simplified
Array(2048) [ "的", "一", "是", "在", "不", "了", "有", "和", "人", "这", … ]
> bip39.wordlists.english
undefined
```

For a complete list of supported wordlists, check the wordlists/ folder. The name of the JSON file (minus the extension) is the key to access the wordlist.

Runtime Wordlist Switching

You can change the default wordlist at runtime if you dislike the default:

```javascript
> bip39.entropyToMnemonic('00000000000000000000000000000fff')
"あいこくしん　あいこくしん　あいこくしん　あいこくしん　あいこくしん　あいこくしん　あいこくしん　あいこくしん　あいこくしん　あいこくしん　あまい　ろんり"
> bip39.setDefaultWordlist('italian')
undefined
> bip39.entropyToMnemonic('00000000000000000000000000000fff')
"abaco abaco abaco abaco abaco abaco abaco abaco abaco abaco aforisma zibetto"
```

Examples

```javascript
// Generate a random mnemonic (uses crypto.randomBytes under the hood), defaults to 128‑bits of entropy
const mnemonic = bip39.generateMnemonic();
// => 'seed sock milk update focus rotate barely fade car face mechanic mercy'

bip39.mnemonicToSeedSync('basket actual').toString('hex');
// => '5cf2d4a8b0355e90295bdfc565a022a409af063d5365bb57bf74d9528f494bfa4400f53d8349b80fdae44082d7f9541e1dba2b003bcfec9d0d53781ca676651f'

bip39.mnemonicToSeedSync('basket actual');
// => <Buffer 5c f2 d4 a8 b0 35 5e 90 29 5b df c5 65 a0 22 a4 09 af 06 3d 53 65 bb 57 bf 74 d9 52 8f 49 4b fa 44 00 f5 3d 83 49 b8 0f da e4 40 82 d7 f9 54 1e 1d ba 2b ...>

// Async version (preferred for non‑blocking operations)
bip39.mnemonicToSeed('basket actual').then(console.log);
// => <Buffer 5c f2 d4 a8 b0 35 5e 90 29 5b df c5 65 a0 22 a4 09 af 06 3d 53 65 bb 57 bf 74 d9 52 8f 49 4b fa 44 00 f5 3d 83 49 b8 0f da e4 40 82 d7 f9 54 1e 1d ba 2b ...>

// With a passphrase (for additional security)
bip39.mnemonicToSeedSync('basket actual', 'a password');
// => <Buffer 46 16 a4 4f 2c 90 b9 69 02 14 b8 fd 43 5b b4 14 62 43 de 10 7b 30 87 59 0a 3b b8 d3 1b 2f 3a ef ab 1d 4b 52 6d 21 e5 0a 04 02 3d 7a d0 66 43 ea 68 3b ...>

bip39.validateMnemonic(mnemonic);   // => true
bip39.validateMnemonic('basket actual'); // => false
```

Entropy ↔ Mnemonic Conversion

```javascript
const bip39 = require('bip39');

// Defaults to BIP39 English word list; uses HEX strings for entropy.
const mnemonic = bip39.entropyToMnemonic('00000000000000000000000000000000');
// => 'abandon abandon abandon abandon abandon abandon abandon abandon abandon abandon abandon about'

// Reversible
bip39.mnemonicToEntropy(mnemonic);
// => '00000000000000000000000000000000'
```
